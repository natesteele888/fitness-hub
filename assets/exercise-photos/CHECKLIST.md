# Power Program — photo checklist

Same idea as the ASL Bengals Winter Build shoot: real photos replace the hand-drawn
pictogram when you open an exercise's info card in the app. Two or three frames of
the same movement, viewed close together in the same spot, read as a **looping
demo** (like Pogo Hop already does). A still pose only needs one frame.

## How to save them

Save straight into this folder (`assets/exercise-photos/`), named with the
exercise's own key (no row numbers or a map file needed — the key is already in
the app's code):

`bw-squat-1.jpg`  `bw-squat-2.jpg`  `bw-squat-3.jpg`

A few are **holds** (just one frame) or general/variable activities that don't
loop well — save those as just `plank.jpg` (one file, no `-1`).

Any size, any crop — I'll fit them in. All frames of one movement should come
from the same video/shoot without moving or zooming the camera, or the
background will jump when it loops. Skip whatever you like; anything without
frames keeps showing the pictogram, same as today.

**Done so far:** Pogo Hop (looping, 3 frames) and A-Skip (1 frame) — reused from
the ASL Bengals shoot since they're the same movements.

Not sure on form for one of these? Search "`<exercise name>` exercise form" on
YouTube, or wait for the in-app Watch Video button once real videos are wired in
for that exercise.
